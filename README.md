# AI Builder — 48-Hour Website

A responsive, advertising-focused single-page website for a 48-hour AI Builder program.

## Run locally

No build step is required.

```bash
python3 -m http.server 5500
```

Open http://localhost:5500

## Edit before launch

- Replace `hello@yourdomain.com` and `YOUR CITY` in `index.html`.
- Replace the GE placeholder compensation card with verified data if you want to publish it.
- Verify all market compensation figures before public use; the ranges in the page are the estimates supplied for the design.
- Confirm appropriate parent/guardian consent and photo/publication permissions for all student profiles before publishing.
- Verify the public incident figures/case-study wording against your source material before advertising them as factual claims.

## Structure

- `index.html` — page content and sections
- `styles.css` — responsive glassmorphism design
- `script.js` — mobile menu, scroll reveals and small metric animation
- `assets/students/` — student photos extracted from the supplied student PDF
